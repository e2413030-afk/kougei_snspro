# 東京工芸大学 厚木キャンパス 学生SNSプロジェクト メンバー募集LP

厚木キャンパスの学生に向けた、メンバー募集用のランディングページ（1枚）。
ビルド不要の静的サイト（HTML / CSS / vanilla JS）。フレームワーク・外部ライブラリは使用していません。

## 構成

```
index.html             本体（ヒーロー + 5セクション + 区切りバンド）
css/style.css          スタイル。色・余白はすべてCSS変数で管理
js/main.js             フェードイン、数値カウントアップ、ヘッダー境界
assets/img/            写真4枚 × webp/jpg × 2サイズ
assets/ogp.png         OGP画像 1200x630（テキストのみで自作）
assets/favicon.svg     favicon（+ favicon-32.png がフォールバック）
serve.ps1              ローカル確認用の静的サーバ
_compare.html          デュオトーン処理の比較ページ（開発用・gitignore対象）
```

## ローカルでの確認

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File serve.ps1 -Port 5173
```

起動後 <http://localhost:5173> を開く。
デュオトーン処理の適用前後は <http://localhost:5173/_compare.html> で確認できます。

WebP / JPEG の両形式は Unsplash の CDN（imgix）から `?fm=webp` `?fm=jpg` で直接取得しています。
ヒーローのみ、元画像の輝度が極端に低いため `&exp=75` で露出を上げた状態で取得しています。

差し替える場合は、次項の brightness 係数を測り直してください。

## 写真のトーン統一

出所の異なる写真が「素材集の寄せ集め」に見えないよう、全画像に同じ処理を当てています。

1. `grayscale(1)` でグレースケール化
2. `brightness()` で画像ごとに明度を正規化（**係数は画像ごとに異なる**）
3. `contrast(1.06)`
4. アクセント色を `mix-blend-mode: color` で重ね、色相を1つに統一

**`brightness` は `contrast` より先に置くこと。** 逆順にすると、暗い画像が contrast の段階で黒に潰れます。

処理後の平均輝度（canvasで実測）:

| 画像 | brightness | 処理前 | 処理後 |
|---|---:|---:|---:|
| ヒーロー | 2.6 | 0.117 | 0.295 |
| 活動内容 | 0.82 | 0.372 | 0.298 |
| 稼働の目安 | 0.52 | 0.588 | 0.298 |
| 区切りバンド | 0.64 | 0.471 | 0.293 |

処理前のレンジ幅 0.471 → 処理後 0.005。

## 表記上の制約

- プロジェクトを「公式」「オフィシャル」と表現しない
- 大学のロゴ、大学指定カラー、大学サイトの意匠を使用しない
- 名称は「東京工芸大学 厚木キャンパス 学生SNSプロジェクト」で統一する
- 大学との関係は事実のみを記載する（「入試課と連携しながら、学生が主体となって運営しているプロジェクト」）
- 実在しない「参加者の声」やフォロワー数などの数値をダミーで置かない
- SNSアカウント名・フォロワー数・投稿は掲載しない

## デザイン上の約束

- **ダーク1テーマ。** `prefers-color-scheme` による切り替えはしない
- アクセント `#4E9DE0` は1色のみ。用途は **CTA・重要数値・フォーカス表示・05セクションのベタ塗り** に限る
- フォントウェイトは 400 と 700 の2種のみ
- 影は使わない。境界は1pxのボーダー。角丸は4px
- 動きはスクロール時のフェードインと、稼働数値のカウントアップのみ
- `prefers-reduced-motion: reduce` で両方とも無効化する

`js/main.js` には、IntersectionObserver が配信されない環境（描画が止まっているタブなど）で
本文が `opacity: 0` のまま残らないよう、2.5秒後に強制表示する保険が入っています。消さないでください。
