# SNS広報プロジェクト 新メンバー募集LP

厚木キャンパス SNS広報プロジェクトの新メンバー募集用ランディングページ。
ビルド不要の静的サイト（HTML / CSS / vanilla JS）。Vercel / GitHub Pages どちらでもそのまま公開可能。

## ローカルでの確認

`index.html` をブラウザで直接開くだけで確認できます。ビルドコマンドは不要です。

## 差し替えが必要な箇所

公開前に、以下のプレースホルダーを実データに差し替えてください。

- [ ] **団体名**: 現在「厚木キャンパス SNS広報プロジェクト」という仮称を使用しています。正式名称が決まったら `index.html` 内の `<title>`・header・footer を差し替えてください。
- [ ] **メンバーの声**: `index.html` の `#voices` セクションに3件のダミーコメントが入っています（`<!-- 差し替え用プレースホルダー -->` のコメント直後）。実際のメンバーのコメントに差し替えてください。
- [ ] **活動写真**: 現在は写真を使わないデザインになっています。写真素材が用意でき次第、`assets/` フォルダに配置し、該当セクションに `<img>` タグを追加してください。
- [ ] **エントリーボタンのリンク先**: `index.html` 内の `href="#"` を、実際の応募フォーム（Googleフォーム等）のURLに差し替えてください（該当箇所: ヘッダーの「エントリー」ボタン、Hero、最終CTAセクション）。

## デプロイ

GitHubリポジトリと連携済みのVercelプロジェクトであれば、`main` ブランチに push するだけで自動的に再デプロイされます。
