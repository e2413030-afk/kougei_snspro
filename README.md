# 東京工芸大学 厚木キャンパス 学生SNSプロジェクト メンバー募集LP

厚木キャンパスの学生に向けた、メンバー募集用のランディングページ（1枚）。
ビルド不要の静的サイト（HTML / CSS / vanilla JS）。フレームワーク・外部ライブラリは使用していません。

## 構成

```
index.html          本体（全セクション）
css/style.css       スタイル。色・余白はすべてCSS変数で管理
js/main.js          スクロール時のフェードインとヘッダー境界のみ
assets/ogp.png      OGP画像 1200x630（テキストのみで自作）
assets/favicon.svg  favicon
assets/favicon-32.png  favicon フォールバック
serve.ps1           ローカル確認用の静的サーバ
```

## ローカルでの確認

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File serve.ps1
```

起動後 <http://localhost:8080> を開く。
`index.html` をブラウザで直接開いても表示は確認できますが、OGP画像やfaviconのパス解決を含めて確認する場合はサーバ経由を推奨します。

## 差し替えが必要な箇所

公開前に、以下を実データへ差し替えてください。いずれもページ上で `【要差し替え：〜】` `【要確認：〜】` として破線枠で表示されています。

- [ ] **募集人数** — `index.html` の `#flow` セクション内、`【要差し替え：募集人数】`
- [ ] **問い合わせ電話番号** — `index.html` の `#entry` セクション内、`【要確認：東京工芸大学 工学部入試課 0120-125-246】`
      この番号は受験生向けの入試相談ダイヤルである可能性が高く、掲載可否が未確認です。確定するまで問い合わせ先として使用しないでください。
- [ ] **プロジェクトの正式名称・略称** — フッター内の `【要差し替え：正式名称・略称】`。不要であれば `.footer-alias` の行ごと削除してください。

差し替え後は、CSSの `.todo` クラスを使っている箇所が残っていないかを確認してください。

## 表記上の制約

このサイトを運用・改修する際は、以下を守ってください。

- プロジェクトを「公式」「オフィシャル」と表現しない
- 大学のロゴ、大学指定カラー、大学サイトの意匠を使用しない
- 名称は「東京工芸大学 厚木キャンパス 学生SNSプロジェクト」で統一する
- 大学との関係は事実のみを記載する（「入試課と連携しながら、学生が主体となって運営しているプロジェクト」）
- 実在しない「参加者の声」やフォロワー数などの数値をダミーで置かない

## デザイン上の約束

- アクセント色は `--accent` の1色のみ。使用先は **CTA・重要数値・リンク・フォーカス表示** に限定し、装飾には使わない
- フォントウェイトは 400 と 700 の2種のみ
- 影は使わず、境界は1pxのボーダーで表現する。角丸は 4〜8px
- 動きはスクロール時のフェードインのみ
